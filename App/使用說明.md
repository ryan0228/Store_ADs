# Shop Ads 使用說明

## 目前部署版本

`D:\CASE\Shop_ADs\App\ShopAds.exe` 已包含必要的 Python 執行環境，不需要另外安裝 Python 套件。日常可直接雙擊 CMD 或執行 EXE。

只有修改原始碼並重新建立 EXE 時，才需要在 `D:\CASE\Shop_ADs\App` 執行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

開發模式可直接執行：

```powershell
python -m shopads validate D:\CASE\Shop_ADs\20260803
python -m shopads generate D:\CASE\Shop_ADs\20260803
```

## 建立作業

1. 在 `D:\CASE\Shop_ADs` 建立 `yyyyMMdd` 目錄。
2. 從 `templates` 複製 `Prod_Description.md`。
3. 建立 `01`、`02` 等數字目錄。
4. 靜態圖片群組加入圖片與 `Img_Description.md`。
5. 單一 GIF 群組只放一個 GIF；不用加入圖片說明。

所有 Markdown 必須儲存為 UTF-8。

## 日常操作

雙擊 `ValidateLatest.cmd` 檢查最新日期作業，再雙擊 `GenerateLatest.cmd` 生成圖片。

生成檔位於：

```text
yyyyMMdd\Result\Generated
```

檢查或人工加工後，將確認成品放入：

```text
yyyyMMdd\Result\Final
```

雙擊 `PackageLatest.cmd` 建立跨電腦 ZIP。沒有完整 Final 時，封裝會拒絕執行。

在另一台電腦驗證封裝：

```powershell
ShopAds.exe verify-package D:\path\PublishPackage-20260803-xxxxxx.zip
```

## 重要規則

- 重新生成只覆蓋 Generated，不會改動 Final。
- 商品名稱不會固定畫到每張圖片上。
- 第一階段不會發布到 Facebook 或 GitHub。
- 不要在 `config.toml` 或日期目錄放入密碼、Token 或私鑰。
- 發生錯誤時，查看畫面上的錯誤代碼與日期目錄下的 `Logs`。
